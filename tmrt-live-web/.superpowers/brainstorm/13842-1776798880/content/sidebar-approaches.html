Sidebar Layout Approaches

How should we separate Input fields from Layer controls?

A

Sidebar Sections + Legend Layer Panel

Sidebar splits into two clearly-styled sections: Inputs (lat/lon/grid/span, neutral background) and Layers (TMRT/DEM/DSM with toggle + opacity, tinted background). The top-right legend expands with layer visibility checkboxes + opacity sliders — a mini layer manager on the map.

B

Sidebar Inputs Only + Floating Layer Panel

Sidebar becomes Inputs only (lat/lon/grid/span + run button). All layer controls move to a floating draggable panel on the map (like QGIS's Layers dock), showing toggle checkboxes + opacity sliders for TMRT, DEM, DSM.

C

Legend Expands to Full Layer Manager

The top-right legend becomes a collapsible layer manager. Clicking it reveals all layers with checkboxes + opacity sliders. Sidebar keeps both inputs and minimal file-upload controls, but no layer toggles there. Layer interaction lives entirely in the legend widget.
